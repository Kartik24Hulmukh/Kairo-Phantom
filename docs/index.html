What Kairo Does

📄 READ + SUGGEST ONLY

Kairo reads your documents and suggests answers. It never writes to or drives your source applications. Every suggestion requires explicit human confirmation.

🔒 Offline-First

Runs entirely on your machine. Zero outbound network calls in sealed mode. No cloud dependency. No data leaves your device.

✍️ Signed Receipts

Every action produces an Ed25519-signed, Merkle-chained receipt. An independent verifier can validate any receipt without trusting Kairo.

🛡️ Injection Defense

106 injection patterns loaded (measured; CI regression floor: ≥56). Committed attack corpus: 25/25 blocked, 0/15 false positives on benign inputs — reproducible with pytest tests/security/test_injection_suite.py -q -s.

Verify It Yourself

Don't trust this page. Run the commands on a clean clone. Every command below references files that exist in the repository.

1

Clone and set up

git clone https://github.com/Kartik24Hulmukh/Kairo-Phantom.git
cd Kairo-Phantom
pip install -r requirements-test.txt
2

Run the Python suite

# Dependency-light subset — verified on a clean clone with only pytest installed: 28 passed
pytest tests/test_landing_page.py tests/security/test_injection_suite.py -q

# Full suite (needs requirements-test.txt) — verified on a clean clone: 1005 passed, 7 skipped, 0 failed
# (e2e PDF tests need a cached model2vec model; without it they error, not fail)
pytest tests/ -q --ignore=tests/e2e
3

Rust: same command CI runs

# Blocking steps in CI workflow "Tier 1 — Verify (CPU)": cargo fmt, clippy -D warnings, build, test
cargo test --workspace --exclude phantom-overlay

phantom-overlay is excluded exactly as in CI (it needs Tauri system libraries). No Rust pass/fail counts are asserted here — CI enforces them as blocking steps.

Scripted Demo (60 seconds)

This demo runs entirely offline. No network, no LLM, no cloud.

1

Redline a contract

python -m kairo.cli redline fixtures/demo/sample_nda.docx fixtures/demo/nda_playbook.json --out demo_output

Produces real OOXML tracked changes (w:ins/w:del) on the NDA.

2

Seal the air-gap

python -m kairo.cli redline fixtures/demo/sample_nda.docx fixtures/demo/nda_playbook.json --sealed --out demo_sealed

Activates sealed mode, blocks all outbound connections, writes air-gap report.

3

Verify the signed receipt

python tools/verify_receipts_external.py demo_output/audit_log.json

Independently verifies the Ed25519-signed, Merkle-chained audit log — without trusting Kairo.

What Kairo Does NOT Do

  • Write to or drive source applications (Word, Excel, desktop) — v1 is READ + SUGGEST ONLY
  • Act as a multi-domain expert swarm or router
  • Operate as a collaborative/cloud-by-default layer
  • Auto-apply any suggestion without explicit human confirmation
  • Allow the model to self-certify a bounding box — the verifier independently re-checks every citation
